# Qwen3-ASR 真实洗车素材 A/B 验证记录

> 日期：2026-08-20  
> 范围：本机转写与强制对齐链路，不包含视觉模型、智能编排或成片渲染  
> 结论：Qwen 链路可用；Whisper 继续作为默认模型，等待人工参考稿评分后再决定是否切换默认值

## 样本与方法

- 样本：项目 `project_5c47bbcf-d607-4003-a02c-9f36a1c723e8` 的 17 段真实洗车口播，总音频时长 43.886 秒。
- Whisper 对照：已完成生成版本 `generation_fb5886eb-05dd-4427-98c7-67ee1b533bf1` 中保存的同批转写。
- Qwen 路径：原视频提取为单声道 16 kHz PCM WAV，调用本机 `Qwen/Qwen3-ASR-1.7B`，再将完整文本交给 `Qwen/Qwen3-ForcedAligner-0.6B`。
- 时间戳验收：每个非空文本必须同时有词级和片段级时间项；所有范围满足 `0 <= startMs < endMs <= durationMs`，并按开始和结束时间非递减排列。
- 限制：当前没有逐字人工参考稿。下表的“观察”仅比较文本可读性与洗车语境合理性，不能当作字符错误率或准确率结论。

## 汇总结果

- Qwen 转写成功：17/17。
- Qwen 强制对齐合同有效：17/17。
- Qwen 逐段转写与对齐累计耗时：18.065 秒；模型首次加载另约 13.7 秒。该数字仅代表本机单次顺序运行，不是性能承诺。
- 依据洗车语境可见的明显改善迹象：至少 7 段，例如“全车吸尘”“轮胎上蜡”“脏兮兮，洗完像新的一样”“脚踏板”“洗得很仔细”。
- 两模型都存在需要人工复核的短句，例如“把电脑拆下来”“出风口、中控台都是用细节”。

## 应用合同验证

除直接模型批量测试外，还临时启动了只监听 `127.0.0.1:8010` 的网关，并通过主应用 `Qwen3AsrTranscriptionProvider` 完成真实 HTTP 验证：

- 健康检查同时报告 ASR 与 ForcedAligner `ready: true`，模型 ID 精确匹配。
- 创建的版本快照包含唯一 `providerId`、ASR 模型、对齐模型、语言、音频配置、词表配置和服务版本。
- multipart 转写与对齐返回了 `provider: qwen3-asr` 的 `NormalizedTranscript`。
- 中文冒烟音频得到 18 个有效字级时间项，片段范围为 80–5280 ms。
- 测试结束后已关闭临时网关；8010 无监听，GPU 显存回到本机空闲基线。

## 默认模型决策

当前保持 `speaches-whisper` 为默认值，Qwen 作为用户显式选择的中文增强选项。理由是：本轮已经证明 Qwen 链路真实可用，并显示出多处领域词改善迹象，但没有人工参考稿，无法计算 CER、漏字率、专业词准确率或字幕边界偏差。切换默认值前应为这 17 段补充人工校对文本与重点词，再以固定脚本评分；不根据模型名称或主观挑例切换生产默认值。
