# AI 视频编排系统

这是一个本地可运行的“完整原片自动编排”工作台。用户创建项目并一次上传多个视频后，系统会保留每个原始文件不变，并行执行语音转写和客观画面理解；全部素材完成后由一次整批模型调用结合真实口播、画面文字和客观画面证据确定广告叙事作用，再按**口播叙事优先、画面衔接辅助**生成唯一播放顺序。Remotion 依据经过校验的时间线完整拼接每段原片，同时输出无字幕和烧录字幕两份 MP4；Caption JSON 与 WebVTT 仍作为独立产物生成。

## 外部免费测试页

测试人员只需要上传素材、查看进度和下载成片。自动重试耗尽或任务需要处理时，公网端只提示等待制作方，不提供重试按钮；管理员在本机独立监控窗口确认错误和模型连接后，才能从断点继续。模型密钥、完整模型往返、删除和关机接口不会通过公网测试网关开放，视频分析、AI 编排、字幕和渲染仍在本机执行。

“开启公网测试”命令窗口继续输出测试人员操作和进度摘要，同时自动打开 `http://127.0.0.1:8791/admin` 独立管理员窗口。该窗口按 2.5 秒刷新公网任务，展示十个批量处理阶段、自动恢复次数、原始错误、中转站程序输入/模型输出、首字节/首事件/超时阶段，并可测试或切换已加密保存的 API Key。任务进入 `needs_attention`、`failed` 或 `cancelled` 后才显示人工重试；重试会保留已完成检查点，并可把该失败版本显式改绑到所选 Key。管理员端口只监听 `127.0.0.1:8791`，Cloudflare 仍只转发 `8790`，且写操作额外要求同源和本机确认请求头。完整 Key 不进入浏览器、日志或响应。

1. 先正常启动洗车编排程序，确认本机后端 `http://127.0.0.1:8787` 可用。
2. 双击工作区根目录的 `开启公网测试.cmd`，输入至少 6 位的本次测试访问码，再输入 `1–30` 的画面理解并发数（直接回车默认 `1`）。脚本会构建网页、启动只监听 `127.0.0.1:8790` 的公网测试网关和只监听 `127.0.0.1:8791` 的管理员端口，自动打开独立管理窗口，再在前台启动 Cloudflare Quick Tunnel。
3. 把终端显示的 `https://...trycloudflare.com/test` 地址和访问码发给测试人员；保持该终端、本机程序和电脑在线。
4. 测试结束后双击 `关闭公网测试.cmd`；也可以在开启窗口按 `Ctrl+C`。关闭命令会停止同一网关进程中的 `8790` 公网端、`8791` 本机管理端及指向 `8790` 的 Quick Tunnel，不关闭 `8787` 主程序，也不删除任务、素材或成片。

命令行方式仍可使用 `powershell -ExecutionPolicy Bypass -File .\scripts\start-public-test.ps1` 和 `powershell -ExecutionPolicy Bypass -File .\scripts\stop-public-test.ps1`。开启时可用 `-VisualConcurrency 3` 直接指定并发；如已构建最新网页可加 `-SkipBuild`；如端口冲突可分别用 `-TestPort` 和 `-AdminPort` 调整，Cloudflare 只应指向 `TestPort`。并发值只写入之后新建的公网测试任务，已创建任务保留原快照。`cloudflared.exe` 需要位于 `PATH`，或位于 `%LOCALAPPDATA%\Programs\cloudflared\cloudflared.exe`。不要把 Tunnel 指向管理端口、Vite 或 `8787`，否则会绕过测试网关的窄接口边界。

## 产品保证

- 原始视频一经保存即不可覆盖、裁切、转码、调色、降噪、变速或改写音轨。
- 平衡理解模式会在本地将早、中、晚三帧合成为一张带 A/B/C 时间标签的 JPEG 联系表，并且只向视觉模型发送这一张图片；等待自动重试或已中断的版本会保留恢复所需的受控临时产物，最终成功后才按清理策略删除。
- 无音轨视频得到空转写/空字幕，但仍可参与视觉理解和完整拼接。
- 编排模型不能读取原始音频或完整视频，也不能返回 JSX、Remotion 代码、Shell、路径或帧数。
- 每个有效素材必须恰好完整播放一次；时间线由程序而非模型计算，使用 contain、原音量 1 和直接切换。
- 每个版本保留一份无字幕成片和一份烧录字幕成片；同一个字幕开关同时决定预览字幕显示和 MP4 下载版本，旧版本缺少字幕成片时只补渲染该派生产物。

## 本地运行

~~~powershell
pnpm install
pnpm dev
~~~

打开 [http://127.0.0.1:5173/](http://127.0.0.1:5173/)。创建项目、上传 MP4/WebM/MOV，再点击“开始自动编排”。每个文件最大 250 MB，每个项目最多 50 个素材。

首次服务端渲染会由 Remotion 准备 Chrome；实际耗时取决于素材总时长、分辨率和本机性能。

## 转写与模型配置

开发模式下（默认 DEMO_MODE=true），未配置服务时系统仍会真实探测、截图、编排和渲染，但转写采用明确标记的空结果、视觉/编排采用确定性本地降级。因此它适合验证完整链路，不能替代真实语言或视觉理解。

要处理真实语音，请配置本机 Qwen3-ASR / ForcedAligner 网关和兼容 Responses API 的视觉/编排中转：

~~~env
QWEN_ASR_BASE_URL=http://127.0.0.1:8010
QWEN_ALIGN_BASE_URL=http://127.0.0.1:8010
QWEN_ASR_MODEL=Qwen/Qwen3-ASR-1.7B
QWEN_ALIGN_MODEL=Qwen/Qwen3-ForcedAligner-0.6B
QWEN_ASR_TIMEOUT_MS=600000
QWEN_ASR_MAX_RETRIES=2

RELAY_BASE_URL=https://relay.example.com/v1
RELAY_API_KEY=
RELAY_MODEL=gpt-5
~~~

Qwen 网关健康检查不会加载模型；启用时同时加载 ASR 与 ForcedAligner，关闭时必须返回显存分配量和保留量均为 0 的确认。程序启动器会先检测 Docker 引擎，服务就绪后自动启用 Qwen；检测、网关启动或模型加载失败时会保留原始错误并在设置页提供重试。运行中的视频版本会阻止关闭模型。

Qwen 返回的词级与片段级时间戳统一使用毫秒，并与模型、对齐器和分片策略一起保存到生成版本快照。模型的所有结构化输出都经过 Zod 契约校验，非法编排最多自动修复两次。

完整的组件边界、API、存储策略和运行排错说明见 [docs/auto-video-orchestrator.md](docs/auto-video-orchestrator.md)。
